# Naetwork

Premium career session platform connecting candidates with experienced professionals.

## Sessions
- Mock Interview
- CV & LinkedIn Review  
- Informal 1:1
- Career Advice

## Business Model
- Professionals set price: DKK 300–2,000 / session
- Platform fee: 15% (7.5% when donating to Kraeftens Bekaempelse)

## Stack
- Next.js 15 + React 19
- Supabase (auth + database)
- Tailwind CSS
- Resend (email)
- Vercel (hosting)
